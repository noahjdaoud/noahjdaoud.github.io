Privacy policy: nlprints-rclone

nlprints-rclone is a private tool used only by its owner (NLPrints). It uses the Google Drive API with the drive.file scope to upload and update files that the tool itself created in the owner's Google Drive.

  • It only accesses files it created itself. It cannot see other files in the Drive.
  • No data is collected from, shared with, or sold to anyone.
  • Access tokens are stored only on the owner's own devices and private cloud environment.
  • Access can be removed at any time in the Google account settings (Security, Third-party access).

Contact: via the NLPrints profile on MakerWorld.
